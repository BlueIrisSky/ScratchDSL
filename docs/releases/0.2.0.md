# ScratchDSL 0.2.0（过渡版）

**这是过渡预发布版本，包含较大的语法变化，不兼容 0.1.0 源码。后续过渡版本仍可能大幅调整语法，暂不承诺语法稳定。** 升级前请备份项目源码，并同时更新编译器与 VS Code 插件。

## 语法变化

- 代码体使用冒号、换行和缩进，绿旗事件写成 `start:`。
- 控制流使用 `if` / `elif` / `else`、`loop`、`while <条件>`；`while true:` 生成“重复执行”积木。
- 命令不再包 `[]`。所有接受普通值或报告积木的输入槽都必须使用圆括号，例如 `等待(1)秒`；布尔输入使用 `<...>`。
- 删除 `var` / `list` 声明，按赋值右侧推断数据种类：`score = 0` 是变量，`tasks = {}` 是列表。确定种类后不能互转，可见作用域内的同名变量/列表冲突会在 IDE 标红。
- 赋值使用 `=`、`+=`、`-=`、`*=`、`/=`、`%=`。算术表达式按优先级展开积木，列表赋值会清空并重新填入内容。
- 数据名称只允许普通标识符，引用使用裸名称；菜单选项使用单引号，是否需要外层圆括号由输入槽决定。
- 第三方扩展支持 C 型积木及多个分支，按文字和输入槽位置匹配。

```scratch
score = 0
tasks = {}

start:
    score = 1+2*3
    tasks = {"开始", 1}
    loop 3:
        等待(1)秒
        score += 1
```

旧语法不会自动兼容。完整规则见[语法文档](https://github.com/BlueIrisSky/ScratchDSL/blob/v0.2.0/docs/syntax.md)。

## 实现与编辑器

清理旧语法的不可达分支、重复扫描和无效状态传递，减少语义绑定中的临时分配。VS Code 的高亮、补全、错误提示与新语法同步，示例和文档也已更新。

VSIX 的服务端目录只打包编译器和依赖许可证，避免旧 Node 运行时等本地残留混入发行包。

发布流程在 Linux / Windows 上验证编译器，在 Windows 上验证 PATH 处理及打包后的 VS Code 插件，再核对安装包、便携版和 VSIX 使用相同的编译器。

## Windows x64 下载

- `Install.exe`：离线安装包，包含编译器与语言服务器，并加入用户 PATH。
- `scratchdsl-0.2.0-windows-x64.zip`：便携版，包含 CLI、文档、示例与许可证。
- `scratchdsl-0.2.0-win32-x64.vsix`：VS Code 插件，内含编译器与语言服务器。
- `sbdsl.exe`：单独的编译器与语言服务器。
- `SHA256SUMS.txt`、`release-manifest.json`：文件校验值及对应的源码提交。
- `LICENSE`、`THIRD_PARTY_NOTICES.txt`：项目及第三方依赖许可证。

运行时无需另外安装 Rust 或 Node.js。
