# ScratchDSL 0.3.0（过渡版）

**这是过渡预发布版本，包含不兼容 0.2.0 的语法变化，暂不承诺语法稳定。** 升级前请备份项目源码，并同时更新编译器与 VS Code 插件。

本文保留 0.3.0 发布时的语法。升级到 0.4.0 请参阅[0.4.0 发布说明](0.4.0.md)。

## 语法变化

- `sprite`、`stage`、`init` 声明块也必须在末尾、与头部相同缩进的位置写 `end`。0.2.0 中只有事件、自制积木、段积木和控制流要求 `end`，现在所有带缩进体的结构规则统一了：

```scratch
sprite "玩家":
    init:
        pass
    end
    start:
        移动(10)步
    end
end
```

- 布尔运算符改用英文关键字：`and`、`or`、`not` 替代 `与`、`或`、`不成立`：

```scratch
if <<hp < 2> and <score > 100>>:
    说 ("危险")
end
while <not <游戏结束 ?>>:
    移动 (10) 步
end
```

旧写法不会自动兼容，编译器会报错并指出位置。完整规则见[语法文档](https://github.com/BlueIrisSky/ScratchDSL/blob/v0.3.0/docs/syntax.md)。

## 实现与编辑器

修复成员声明块不识别头部缩进 `end` 的解析问题；语言服务器与编译器的 tab 缩进宽度计算统一为制表位语义；清理未使用的 API 与重复扫描逻辑。VS Code 高亮规则与新的布尔关键字同步。

## Windows x64 下载

- `Install.exe`：离线安装包，包含编译器与语言服务器，并加入用户 PATH。
- `scratchdsl-0.3.0-windows-x64.zip`：便携版，包含 CLI、文档、示例与许可证。
- `scratchdsl-0.3.0-win32-x64.vsix`：VS Code 插件，内含编译器与语言服务器。
- `sbdsl.exe`：单独的编译器与语言服务器。
- `SHA256SUMS.txt`、`release-manifest.json`：文件校验值及对应的源码提交。
- `LICENSE`、`THIRD_PARTY_NOTICES.txt`：项目及第三方依赖许可证。

运行时无需另外安装 Rust 或 Node.js。
