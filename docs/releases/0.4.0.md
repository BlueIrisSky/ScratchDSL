# ScratchDSL 0.4.0

0.4.0 为稳定版，包含不兼容 0.3.0 的语法调整。升级时请同时更新编译器和 VS Code 插件，并按下面的步骤迁移源码。

## 从 0.3.0 升级

- 删除用于结束代码体的独立 `end` 行，保留其余语句的缩进。`sprite`、`stage`、`init`、事件、自制积木、段积木和控制流统一在缩进回退或文件结束时结束；旧 `end` 结束语法不再接受。
- 空代码体必须缩进写 `pass`，不能只留空行或注释。`elif`、`else` 仍与对应头部对齐，扩展 C 型积木的多个分支继续使用同级 `else:`。
- 将 `等待(秒数)秒` 改为 `sleep(秒数)`，例如 `等待(1)秒` 改成 `sleep(1)`。单位仍为秒，参数可以是变量或报告积木；不保留旧写法作为别名。`等待直到`、`广播…并等待` 和 `询问…并等待` 保持原写法。

```scratch
sprite "玩家":
    init:
        pass
    start:
        loop 3:
            移动(10)步
            sleep(1)
        说("完成")
```

完整规则见[语法文档](https://github.com/BlueIrisSky/ScratchDSL/blob/v0.4.0/docs/syntax.md)。

## 编译器与编辑器

解析器按缩进和文件结束确定代码体范围，对旧 `end` 和缺少缩进体的代码报告错误。内置等待积木使用 `sleep`，仍生成 Scratch 的 `control_wait`。

语言服务器补全不再插入 `end`，新代码体默认使用可替换的 `pass`。VS Code 高亮、补全、新项目模板和示例同步采用新语法。

## Windows x64 下载

- `Install.exe`：离线安装包，包含编译器与语言服务器，并加入用户 PATH。
- `scratchdsl-0.4.0-windows-x64.zip`：便携版，包含 CLI、文档、示例与许可证。
- `scratchdsl-0.4.0-win32-x64.vsix`：稳定版 VS Code 插件，内含编译器与语言服务器。
- `sbdsl.exe`：单独的编译器与语言服务器。
- `SHA256SUMS.txt`、`release-manifest.json`：文件校验值及对应的源码提交。
- `LICENSE`、`THIRD_PARTY_NOTICES.txt`：项目及第三方依赖许可证。

运行时无需另外安装 Rust 或 Node.js。
